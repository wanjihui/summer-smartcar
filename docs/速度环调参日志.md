## 已知问题

- 编码器标定未确认（PPR/ENC_TO_CMS可能与实际有偏差）
- 右轮响应比左轮慢（机械差异），Out_R波动更大
- 速度值绝对精度不保证，按VOFA波形调参即可

## VOFA通道

```
Ch1: Target_L (cm/s)    Ch4: Target_R (cm/s)
Ch2: Actual_L (cm/s)    Ch5: Actual_R (cm/s)
Ch3: Out_L (duty)       Ch6: Out_R (duty)
Ch7: err (pixel)
```

## 调参记录

### 第1轮 — 2026-08-04

**参数**：Kp=2.0, Ki=0.5, Kd=0.0, OutDeltaMax=8

**现象**：右轮编码器方向反了，Actual_R为负值。PID Out_R拉到上限30仍然追不上。

**修复**：ISR里右轮编码器取反 `-(float)encoder_get_right_speed()`

### 第2轮 — 2026-08-04

**参数**：Kp=0.8, Ki=0.5, Kd=0.0, OutDeltaMax=8, 右轮编码器取反

**现象**：
- 右轮Actual转为正值，跟踪正常
- 但Out_L在11~25波动，Out_R在-12~+30剧烈波动（右轮Out波动是左轮3倍）
- Actual≈48-53，Target=49.3（当时用脉冲单位），跟踪误差可接受

**修复**：Kp 0.8→0.5, Ki 0.5→0.3, Kd 0→0.05

### 第3轮 — 2026-08-04

**参数**：Kp=0.5, Ki=0.3, Kd=0.05, OutDeltaMax=4, OutMax=±30, base_spd=14(1.4m/s), cur_spd=10(1.0m/s)

**现象**：
- PPR修正后速度正常，Actual≈135-145追上Target=140 ✓
- 左轮跟踪良好：Out_L≈15-25，Actual_L≈140
- **Out频繁饱和在±30**：弯道时两轮都撞到上限
- err=222时车完全偏离赛道，Target_L=88 Target_R=112 diff=12仍正常
- 弯道后右轮速度崩溃：Actual_R从正常→负值，车几乎停下
- 弯道后右轮速度崩溃：Actual_R从正常→负值，车几乎停下
- **Out=30只出现在瞬态**（OutDeltaMax限幅导致加减速跟不上），稳态直道Out≈25

**修复**：
- Motor_MAX_DUTY 30 → 50（放开duty上限）
- OutDeltaMax 4 → 6（加快瞬态响应）
- PPR确认1024线×4x=4096，ENC_TO_CMS=1.117
- 速度绝对值可能有偏差，但波形趋势可用于调参

### 第4轮 — 2026-08-04

**参数**：Kp=0.5, Ki=0.3, Kd=0.05, OutDeltaMax=6, OutMax=±50, base_spd=14(1.4m/s), cur_spd=10(1.0m/s)

**数据**：
```
直道稳态: 140,142,22 / 140,141,4   ← 左Out=22 右Out=4，同Target同Actual但Out差5倍！
弯道加速: 140,115,50 / 140,112,41  ← Target=140，Actual只到115，Out饱和50
弯道右轮: 102,78,50 / 102,161,20   ← 右轮实际值跳变(78→161→70)，不稳定
```

**现象**：
- 直道跟踪OK：Actual≈140，但左右Out差异悬殊（右轮只需要左轮1/5的duty）
- **瞬态响应太慢**：Target突增时Actual跟不上，Out拉满50仍然追不上
- 右轮Actual偶尔跳变（78→161→70），可能是编码器噪声或机械滑差
- 弯道中右轮速度坍塌（Actual=48实际不到Target一半）

**修复**：
- Kp 0.5→1.0（加快瞬态响应）
- Ki 0.3→0.2（防过冲）
- 右轮机械/编码器问题待排查

### 第7轮 — 2026-08-04

**参数**：Kp_L=1.0 Ki_L=0.15 Kd_L=0.05 / Kp_R=1.5 Ki_R=0.25 Kd_R=0.10, OutDeltaMax=6, OutMax=±50, base_spd=10, cur_spd=7

**データ**：
```
启动: Target=70, Out=50饱和6周期后追上, Actual短暂超调(80)→回落
直道: Target=100, Out_L≈18-25, Out_R≈-3~+10, Actual≈100±5 ✓
减速: Target 100→70, Out降至-33~-17, Actual跟踪正常
右Out减速后恢复极慢: Target=70时Out_R=-24持续, Actual_R已≈Target
弯道err=-203: 车完全偏离赛道, Out_L=50饱和, Actual_L=56跟不上
```

**現象**：
- 直道稳态OK
- **右轮减速后Out长期为负**（积分累积恢复太慢），即使Actual已接近Target
- err=-203及后续数据为手动拦截导致，不纳入分析
- Kd_R=0.10未明显改善右轮抖动

**修复**：
- **加PID自动复位**：目标速度跳变>30%时自动清空积分（防Out卡在负值）
- 不改增益

### 第8轮 — 2026-08-04

**参数**：Kp_L=1.0 Ki_L=0.15 Kd_L=0.05 / Kp_R=1.5 Ki_R=0.25 Kd_R=0.10, OutDeltaMax=6, OutMax=±50, base_spd=10, cur_spd=7, PID自动复位(Δ>30%)

**データ（去尾）**：
```
启动 0→100: Out=50, Actual 8周期追上, 轻微超调(109)→快速回落
直道稳态: Out_L≈18-28, Out_R≈-10~+15, Actual≈100±8 ✓
减速 100→70: PID复位, Out_L=-20→+18平滑恢复, Out_R=-26→+20 ✓ 
再加速 70→100: PID复位, Out峰值47, 6周期追上, 未饱和 ✓
```

**現象**：
- **PID自动复位有效** ✓：减速后再加速Out不再卡在负值，恢复速度明显加快
- 右Out震荡幅度收窄(-10~+15 vs 第7轮-24~+10)
- 直道稳态跟踪稳定，Actual±8以内
- Out不再撞50上限（峰值47.5）
- 左右Out不对称仍存在（左~22, 右~0），属机械差异

**結論**：速度环基本调通。左右不对称是硬件问题。可小幅降左Kp(1.0→0.8)进一步抑制左Out波动，或直接进入下一阶段。
