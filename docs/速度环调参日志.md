## 已知问题

- 编码器标定未确认（PPR/ENC_TO_CMS可能与实际有偏差）
- 右轮响应比左轮慢（机械差异），Out_R波动更大
- 速度值绝对精度不保证，按VOFA波形调参即可

## VOFA通道

```
Ch1: Target_L (cm/s)    Ch4: Target_R (cm/s)
Ch2: Actual_L (cm/s)    Ch5: Actual_R (cm/s)
Ch3: Out_L (duty)       Ch6: Out_R (duty)
Ch7: err (pixel)        Ch8: steer_dbg (°)     Ch9: gyro_z (°/s)
```

### VOFA传输方式（2026-08-04 更新）

**TX空中断 + 环形缓冲区，非阻塞，不卡主循环。**

| 项目 | 说明 |
|------|------|
| 原理 | 主循环 snprintf 格式化 → 写入 128 字节环形缓冲区（立即返回）→ UART6 TX空中断逐字节发送 |
| 发送频率 | 隔帧发送 ≈25Hz（可调 vofa_cnt >= N） |
| 波特率 | 115200（≈87μs/字节） |
| 流控 | 无线模块 RTS 引脚：RTS高时暂停ISR发送，主循环 poll 恢复 |
| CPU开销 | ~1-2%（每字节一次中断，单次ISR≈10-20周期@120MHz） |
| 旧方案（已废弃）| wireless_uart_send_buffer 阻塞 11ms/帧（115200波特×128字节），主循环50%时间卡住 |
