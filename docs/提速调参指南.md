## 一、控制架构总览

```
摄像头 50Hz
    │
    └→ vis_deal() → err (像素偏差)
                          │
              ┌───────────┴───────────┐
              ↓                       ↓
        servo_update()          motor_update()
        舵机位置式PD             |e|→速度过渡+LPF
              │                 steer_dbg→Ackermann差速
              ↓                       │
        servo_set_angle()       Motor_PID.Target
        steer_dbg ──────→ (差速输入)   │
                              TIM6 ISR 200Hz
                                      │
                              encoder → PID_INC_Update()
                                      │
                              motor_set_left/right()
```

## 二、舵机控制（位置式PD）

### 公式

```
e = err（死区±2px，方向翻转后）
kp = servo_kp1 + servo_kp2 × |e|          ← 非线性P
kd = 直道D + (弯道D - 直道D) × clamp      ← |e|5→15平滑过渡

pd = kp × e + kd × (e - last_e)

angle = pd × (max_cha / 35.0)             ← 像素→角度
angle = clamp(angle, ±max_cha)            ← 限幅±13°
angle = slew_limit(angle, ±max_add)       ← 步进限制5.5°/帧
target = center + angle
```

### 参数表

| 参数 | 默认值 | 作用 | 提速时调整 |
|------|--------|------|-----------|
| **servo_kp1** | 0.3 | 基础比例增益 | 高速需增大(0.4~0.6) |
| **servo_kp2** | 0.026 | 二次增益(大err时更强) | 保持 |
| **servo_kd** | 0.0 | 弯道D(大err) | 弯道抖时加(0.05~0.15) |
| **servo_kd_str** | 0.35 | 直道D(小err) | 直道抖时加大 |
| **servo_max_cha** | 16.0° | 最大偏角 | 高速已加大到16° |
| **servo_max_add** | 5.5°/帧 | 步进限制(275°/s) | 高速可加大(7~10)，防迟钝 |
| **servo_dead** | 2px | 死区 | 保持 |
| **servo_center** | 95.2° | 中位 | 机械变化时调整 |
| **servo_dir** | 1(翻转) | 方向 | 方向反了切换0/1 |
| **gyro_kd** | 0.03 | 陀螺仪阻尼(直道) | 当前禁用 |
| **gyro_kd_curve** | 0.03 | 陀螺仪阻尼(弯道) | 当前禁用 |

### 特有机制

- **回正软化**：e×Δe<0（靠近中线时）→ P自动软化到kp1×0.6，防冲过头
- **Kd平滑过渡**：|e|从5→15，kd从直道D平滑过渡到弯道D

## 三、速度环（增量式PID，ISR 200Hz）

### 公式

```
// motor_update() — 50Hz视觉帧，设目标速度
e = err（死区+翻转，同舵机）

// 连续速度过渡（替代二元切换）
ratio = clamp((|e|-8)/10, 0, 1)            ← |e|8→18线性插值
base_spd_dms = straight_spd×(1-ratio) + curve_spd×ratio
base_cms = base_spd_dms × 10               ← dm/s→cm/s

// 非对称低通滤波（入弯快降速，出弯慢加速防振荡）
alpha = (raw < filtered) ? 1.0 : 0.5
base_cms = filtered + alpha × (raw - filtered)

// === Ackermann乘法差速（舵角→差速比）===
δ = steer_dbg (°)                           ← 舵机实际偏角
if (|δ| > 4°)                               ← 死区4°
    ang_rad = δ × π/180                     ← tan(θ)≈θ
    ratio = ang_rad × W/L × gain             ← W=0.05475m L=0.20m
Target_L = base_cms × (1 + ratio)           ← 乘法！外轮加速
Target_R = base_cms × (1 - ratio)           ← 乘法！内轮减速

目标跳变>50% → PID复位 + Out预载Target×0.125   ← 前馈

// TIM6 ISR — 200Hz
Actual = 编码器脉冲 × 1.117                   ← →cm/s

// PID_INC_Update()
e0 = Target - Actual
delta = Kp×(e0-e1) + Ki×e0 + Kd×(e0-2e1+e2)
delta = clamp(delta, ±OutDeltaMax)
Out += delta
Out = clamp(Out, ±OutMax)
motor_set(Out)
```

### 参数表（左右独立）

| 参数 | 左轮 | 右轮 | 作用 |
|------|------|------|------|
| **Kp** | 0.5 | 1.0 | 比例：误差变化率→duty增量 |
| **Ki** | 0.12 | 0.20 | 积分：稳态误差→duty增量 |
| **Kd** | 0.10 | 0.15 | 微分：加速度阻尼 |
| **OutDeltaMax** | 6.0 | 6.0 | 单次duty变化上限(防wheelspin) |
| **OutMax** | ±70 | ±70 | duty绝对上限 |

### 目标速度参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| **base_spd** | 16 (1.6m/s) | 直道目标速度(dm/s) |
| **cur_spd** | 11 (1.1m/s) | 弯道目标速度(dm/s) |
| **速度过渡** | |e| 5→15线性 | 连续过渡替代二元切换 |
| **非对称LPF** | α入=1.0 α出=0.5 | 入弯瞬间降速，出弯平滑 |

### Ackermann差速参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| **ack_gain** | 1.0 | 差速增益（菜单可调，0.1~5.0） |
| **轴距 L** | 0.20 m | 前轮中心→后轮中心 |
| **轮距 W** | 0.05475 m | 左右后轮中心距 |
| **死区** | 4.0° | 舵角<4°无差速 |
| **公式** | `ratio = tan(δ)×W/L×gain` | 乘法：`base×(1±ratio)` |

**差速效果速查（gain=1.0）：**

| 舵角δ | ratio | 160cm/s时差速 | 110cm/s时差速 |
|-------|-------|-------------|-------------|
| 4°(死区内) | 0% | 0 cm/s | 0 cm/s |
| 8° | 3.8% | 6.1 cm/s | 4.2 cm/s |
| 12° | 5.7% | 9.2 cm/s | 6.3 cm/s |
| 16°(满舵) | 7.9% | 12.6 cm/s | 8.6 cm/s |

**调法**：推头(转不过来)→加大gain / 甩尾→减小gain

### 前馈+复位

| 参数 | 值 | 说明 |
|------|-----|------|
| **FF_GAIN** | 0.125 | 25duty≈200cm/s的经验映射 |
| **PID复位阈值** | 目标变化>50% | 大幅变速时清零积分+预载duty |

## 四、提速步骤（按顺序）

### 第1步：提直道速度

```
base_spd: 10 → 12 → 14 → 16 → 18 → 20
每步跑一圈，观察VOFA：
  - Out_L是否震荡加剧 → 降Kp_L(0.6→0.4)
  - Out是否撞50上限 → 电机已达极限，停止提速
  - Actual能否跟上Target → 跟不上降速或加大Kp
```

### 第2步：调舵机响应

```
高速时舵机可能感觉"迟钝"，逐步加大：
  servo_max_add: 5.5 → 7.0 → 9.0
  servo_kp1: 0.3 → 0.4 → 0.5
每步跑一圈，看steer_dbg：
  - 直道steer在0附近微摆正常(±2°)
  - 弯道steer打到10-13°正常
  - steer剧烈震荡→降kp1或加kd
```

### 第3步：调弯道速度

```
cur_spd: 7 → 9 → 11
弯道速度太高会推头(转向不足)：
  看err值，如果弯道err持续>30 → 弯道速度太快
  cur_spd保持比base_spd低3-4个单位
```

### 第4步：微调差速（Ackermann gain）

```
ack_gain: 1.0 → 1.5 → 2.0
弯道表现判断：
  推头(车转不过来, err持续偏大)  → ack_gain ↑ (1.0→1.5→2.0)
  甩尾(转向过度, 车尾外滑)       → ack_gain ↓ (1.0→0.7→0.5)
  直线S形摆动                     → 不管gain，死区4°已处理
gain=1.0时效果≈旧方案diff_max=13，安全起点
```

## 五、故障排查

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 直道蛇形摆动 | 舵机Kp过高 | 降servo_kp1 |
| 出弯震荡 | 舵机回正太猛 | 降servo_kd_str |
| 加速时车尾甩 | 差速过大 | 降ack_gain |
| 弯道推头(转不过) | 速度太快/舵角不够/差速不够 | 降cur_spd 或 加大servo_max_cha 或 加大ack_gain |
| Out频繁撞±50 | 电机功率不足 | 降目标速度 |
| 右轮转速异常跳变 | 编码器/机械 | 排查硬件 |
